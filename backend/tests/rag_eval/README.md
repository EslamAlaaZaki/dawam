# RAG evaluation corpus

Documents in `corpus/` were written for this repository by its contributors (no third-party
source) and are released under the repository's Apache-2.0 licence, so they can be
redistributed freely. They describe fictional policies and contain no personal data about real
individuals. The whole set is a few kilobytes, far below the 20 MB limit. `cases.json` holds
each question, its gold passage ids (`<document>#<section heading>`) and a recorded answer that
cites passages. The maintainer may swap in their own documents: keep the same layout.
